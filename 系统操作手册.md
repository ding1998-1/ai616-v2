# AI Compliance System - Operation Manual

This manual provides instructions for starting, testing, and maintaining the AI Compliance System.

## 🏗️ System Architecture
- **Backend**: FastAPI server providing compliance audit skills and semantic validation.
- **Frontend**: React/Vite application with a premium dashboard and real-time audit console.
- **Database**: 
    - `data/audit_history.json`: Persistent audit records.
    - `data/uploads/`: Permanent storage for uploaded documents.
    - `chroma_db/`: Vector database for compliance rules.

## 🚀 Getting Started

### 1. Prerequisites
Ensure you have Python 3.10+ and Node.js installed.
Install dependencies:
```bash
# Backend
pip install fastapi uvicorn sentence-transformers torch langchain chromadb httpx

# Frontend
cd frontend
npm install
```

### 2. Launching the System
Open two terminal windows:

**Terminal 1 (Backend):**
```bash
python3 backend.py
```
*Note: Wait for "Application startup complete" and "语义校验模型加载成功".*

**Terminal 2 (Frontend):**
```bash
cd frontend
npm run dev
```
*The app will be available at http://localhost:3001/.*

## 🧪 Testing and Verification

### Manual Verification
1.  Open the dashboard at `http://localhost:3001/`.
2.  **Compliance Audit**:
    - Select a matter type (e.g., 重大决策).
    - Paste text or upload a document.
    - Click **Send**.
    - Observe the 5-step audit process in the "AI 智能体执行日志" panel.
3.  **Decision Archive**:
    - Navigate to the **归档中心** tab.
    - Verify that your completed audit appears in the table.
    - Refresh the page to confirm persistence.

### Persistence Check
Verify that files and records are stored on disk:
- Check `data/uploads/` for your uploaded documents.
- Check `data/audit_history.json` for the structured JSON records.

## ⚠️ Troubleshooting
- **LLM Service Error (502)**: Ensure the SGLang service is running at the configured address (`192.168.66.44:8088`).
- **404 Errors**: Ensure both backend and frontend are running. Check `vite.config.js` proxy settings if endpoints are unreachable.
- **Model Load Failure**: Ensure your environment has sufficient memory (approx. 4GB) to load the `paraphrase-multilingual-mpnet-base-v2` model.
