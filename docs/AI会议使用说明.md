# AI 会议合规系统 — 使用说明

> 版本：2026-06-18  
> 适用角色：会议组织者、参会代表、合规管理员

---

## 一、系统概述

AI 会议合规系统覆盖会议的**全生命周期**——从会前议题收集、会中录音转写与实时监控、到会后合规终审与公文归档，实现"三重一大"事项的数字化闭环管理。

### 会议四阶段

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│  01 议题确认  │ → │ 02 会中采集   │ → │ 03 会后终审   │ → │ 04 公文归档   │
│  收问题·成议题 │    │ 录音·认人·标事│    │ 材料核验·合规  │    │ 纪要·签署·防伪 │
│  绑项目       │    │ 件           │    │ 拦截          │    │ 归档          │
└──────────────┘    └──────────────┘    └──────────────┘    └──────────────┘
```

### 系统入口

- **桌面端**：浏览器访问系统 → 左侧导航「AI 会议」
- **手机端**：扫描桌面端二维码，或直接访问 `/mobile-recorder` 路径

## 二、桌面端操作

### 2.1 创建会议

1. 点击左侧「AI 会议」进入会议工作台
2. 点击右上角 **「+ 新建会议」** 按钮
3. 填写会议信息：

| 字段 | 说明 |
|------|------|
| 会议标题 | 如"高新区二期厂房改造追加预算审议" |
| 会议日期 | 自动填入当天，可修改 |
| 会议类型 | 普通企业会议 / 经营例会 / 董事会 / 总经理办公会 / 专题会 / 党委会 / 党组会 |
| 会议模式 | **普通模式**（标准流程）/ **三重一大模式**（强化合规审查） |

4. 点击「创建」→ 自动进入会议工作区

### 2.2 会前：议题确认（阶段 01）

#### 收集问题线索

**方式一：手动录入**
- 在左侧问题收集中，逐条填写问题内容
- 系统自动归类、判断事项类型

**方式二：Excel 批量导入**
- 点击「导入 Excel」上传问题台账
- AI 自动解析、梳理待办、判断议题类型与风险等级
- 支持选择导入条数（1-6 条）

**方式三：二维码扫码提交**
- 点击「分享收集链接」生成二维码
- 参会人手机扫码后可直接提交问题
- 提交内容实时同步到桌面端

#### 生成议题

- 选中需要上会的问题（勾选复选框）
- 点击「AI 生成议题」
- 系统调用 DeepSeek 分析问题内容，自动：
  - 判断事项类型（重大事项/重要干部/重大项目/大额资金）
  - 评估风险等级
  - 生成议题描述和待办建议
- 每个议题可设置**讨论时长**（5/10/15/20/25/30/45/60 分钟）
- 议题列表显示预计总时长

### 2.3 会中：采集与校对（阶段 02）

这是会议进行中的实时操作区，包含五个核心功能区：

#### 📱 录音采集
- 显示手机端录音会话状态
- 支持多台手机同时录音（不同参会人）
- 声纹分轨：AI 自动识别不同说话人
- 实时转写推流到桌面端

#### 👤 声纹与说话人
- 转写文本按说话人分色显示
- 点击说话人名称可**校正身份**（修改姓名/角色/部门）
- 系统学习后自动提升识别准确率

#### 🏷️ 会中快捷标记

在会议进行中，可对任意转写片段快速标记：

| 标记类型 | 用途 | 示例 |
|---------|------|------|
| 决策 | 标记会议决策点 | "同意追加预算 500 万" |
| 待办 | 记录行动项 | "财务部 3 日内完成资金测算" |
| 争议 | 标记分歧点 | "工期问题未达成一致" |
| 材料 | 关联补充材料 | "需补充环评报告" |

#### ⏱️ 议题计时器
- 当前讨论议题显示倒计时
- 剩余 ≤5 分钟黄色警告，≤2 分钟红色警告
- 到时提示 ⏰
- 操作按钮：**开始计时** → **+5 分钟** → **下一议题**（自动开始计时）→ **重置**

#### 📊 实时议题比对
- 每 5 分钟自动送 AI 分析：当前讨论是否覆盖了预设议题
- 比对结果实时显示：哪些议题已讨论、哪些尚未涉及
- 黄色 = 部分覆盖，绿色 = 已充分讨论，灰色 = 尚未涉及

### 2.4 会后：终审（阶段 03）

会议结束后进入合规审查阶段：

#### AI 生成会议成果

点击「**AI 生成会议纪要**」按钮，系统自动生成：

1. **会议摘要** — 会议基本情况概述
2. **章节纪要** — 按议题自动切分章节
3. **决议清单** — 会议形成的正式决策
4. **待办事项** — 责任人、事项、截止时间
5. **合规提示** — 三重一大事项的合规风险提醒

#### 逐条处理建议

- 每条 AI 生成的纪要/决议/待办可**手动编辑**
- 点击「采纳」确认，点击「修改」调整内容
- 支持**补充材料**：上传相关附件

#### 风险拦截

- 对于三重一大事项，系统自动检查：
  - 程序是否合规（如是否经过前置研究）
  - 材料是否齐全
  - 是否存在利益冲突
- 发现问题时标红提示，阻止进入归档

### 2.5 归档：公文导出（阶段 04）

#### 下载会议纪要（Word）

- 点击「**下载会议纪要 DOCX**」
- 系统生成符合公文标准的红头 Word 文档：
  - 红头标题：方正小标宋简体，红色，22pt
  - 正文：仿宋 12pt，首行缩进
  - 章节标题：黑体，加粗
  - 八章结构：基本信息 → 议题 → 摘要 → 纪实 → 纪要 → 决议 → 待办 → 签署确认
  - 表格排版，标准公文页边距

#### 归档确认

- 确认纪要内容无误后，点击「**确认归档**」
- 会议状态变为"已归档"
- 数据进入归档中心，可在「归档中心」页面查询

## 三、手机端操作

### 3.1 加入会议

**方式一：扫码加入**
1. 用手机扫描桌面端展示的二维码
2. 自动打开手机录音页面
3. 如未登录，先进行会议专用注册（输入姓名、部门）

**方式二：直接访问**
- 访问 `https://域名/mobile-recorder?meetingId=xxx`
- 系统自动拉取会议信息

### 3.2 录音操作

1. **选择身份**：在「当前发言人」下拉框中选择自己
   - 多人共用一台手机时，切换发言人后录音自动归属
2. **开始录音**：点击红色录音按钮
   - 首次使用会请求麦克风权限
   - 系统自动检测 Fun-ASR 连接状态（5 秒预检）
3. **实时转写**：语音实时转为文字推送到桌面端
4. **停止录音**：再次点击录音按钮
   - 音频自动上传到服务器归档
   - 上传失败会自动重试一次

### 3.3 降级策略

当语音识别不可用时，系统自动降级：

```
Fun-ASR WebSocket → 浏览器语音识别 → 手动输入文本
```

### 3.4 发言人去重

手机端通过以下机制避免重复：
- 同一台手机连续录音，切换发言人自动切分
- 桌面端可事后校正说话人标签
- 系统基于声纹特征自动聚类

## 四、OA 审批联动

系统内置 OA 流程模拟，可演示事项从发起到归档的完整审批链路：

### 4.1 事项选择

- 从左侧 OA 审批页面选择预置事项模板
- 或从会议生成的待办事项直接发起审批

### 4.2 审批流程

| 节点 | 操作 | 说明 |
|------|------|------|
| 业务部门提交 | 上传材料 | 发起事项，提交初审材料 |
| 合规审查 | AI 自动检查 | 制度匹配、负面清单校验、风险提示 |
| 集体决策 | 前置研究 | 董事会/总经理办公会集体研判 |
| 最终审批 | 签批确认 | 形成审批结论，生成审批凭证 |

### 4.3 风险拦截

- AI 实时检查材料完整性
- 缺失材料标红提示："需补充 XXX 文件"
- 程序不合规自动拦截："任前公示期满前不得进入正式任命节点"

## 六、角色与权限

| 角色 | 权限范围 |
|------|---------|
| **管理员 (admin)** | 创建/编辑/删除任何会议，管理用户，管理规则库 |
| **业务用户 (staff)** | 创建会议，参与自己创建的会议，查看被授权的会议 |
| **参会代表** | 手机扫码参会，提交问题，录音转写 |
| **外部参会人** | 通过会议专用注册加入，仅限当前会议 |

### 会议访问控制

- 会议的**创建者**和同部门成员可访问
- 外部参会人通过会议专用注册后，仅可访问指定会议
- 管理员可访问所有会议

## 七、AI 能力说明

| AI 功能 | 调用时机 | 使用的模型 |
|---------|---------|-----------|
| 议题生成 | 会前导入问题后手动触发 | DeepSeek |
| 实时议题比对 | 会中每 5 分钟自动执行 | DeepSeek（宽松语义匹配） |
| 会议纪要生成 | 进入归档阶段手动触发 | DeepSeek |
| 语音转写 | 手机录音实时推送 | 阿里云 Fun-ASR |
| 声纹识别 | 转写时自动聚类 | 声纹特征分析 |
| 合规审查 | 三重一大模式下的终审阶段 | DeepSeek + 规则库匹配 |

### 降级策略

- 语音识别不可用 → 浏览器内置语音识别 → 手动输入
- LLM 调用超时 → 本地规则降级（>30 字即判定为有效发言）
- 知识库不可用 → 仅基于会议素材生成，不含外部法规参考

## 八、注意事项

1. **录音权限**：首次使用手机录音需授权麦克风，需 HTTPS 环境
2. **网络要求**：手机和桌面端需在同一网络（或通过公网代理）
3. **音频归档**：录音停止后自动上传，上传期间请勿关闭页面
4. **AI 生成耗时**：会议纪要生成约需 30-90 秒，请耐心等待
5. **缓存机制**：纪要生成后自动缓存，再次访问秒出
6. **归档不可逆**：确认归档后会议进入只读状态，如需修改请联系管理员
