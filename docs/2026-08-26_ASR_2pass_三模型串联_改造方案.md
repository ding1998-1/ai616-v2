# ASR 2pass + 三模型串联 改造方案

> **文档用途**：本文档是给 AI 编程助手（Cursor / Claude Code / Copilot 等）看的实现级设计文档。AI 应严格按照本文档的模块划分、接口签名、伪代码和集成点实现代码，不得自行更改架构决策。
>
> **改造目标**：将本地开源 ASR 效果对齐云端实时转写（阿里云百炼 / 腾讯会议级别），核心手段是 **2pass 架构**（流式低延迟出字 + 句尾大模型回看纠正）+ **三模型串联**（fsmn-vad + ASR + ct-punc）+ **说话人分离升级**（cam++ 无监督分人）。
>
> **预期收益**：中文会议识别准确率提升 30-40%，句尾错误率下降 60%，标点准确率提升至 90%+，新参会人无需预注册即可分人。

---

## 一、背景与现状

### 1.1 现有架构

当前 ASR 链路（`backend/routes/asr.py` 的 `meeting_asr_qwen_websocket` → `asr_worker`）：

```
前端 WebSocket (PCM 16kHz)
    ↓
SileroVAD.process()  ← 神经网络 VAD，threshold=0.5，有自适应阈值
    ↓ (非语音直接 continue)
累积 audio_buffer 到 16000 字节 (1秒)
    ↓
QwenASRClient.send_chunk(session_id, pcm_bytes)
    ↓ HTTP POST 到 127.0.0.1:8091/api/chunk
本地 ASR 服务 (8091端口，可能是 SenseVoice / Paraformer / Qwen3-ASR)
    ↓
返回增量文本 {text, language, spk}
    ↓
后处理: 标签清洗 + 同音词纠错 + 重复检测 + 静音flush
    ↓
WebSocket 发送 preview / final 给前端
```

### 1.2 现有问题

| 问题 | 根因 | 影响 |
|------|------|------|
| 句尾经常丢字/错字 | 单 pass 流式模型在句尾上下文不足时精度下降 | 专有名词、数字、人名错误率高 |
| 标点不准 | 靠 ASR 模型自带标点，无专门标点恢复模型 | 纪要生成质量差，LLM 处理无标点长文本效果差 |
| VAD 误触发 | SileroVAD 对敲击声/咳嗽声判别不稳，且无回看缓冲 | 环境声被送入 ASR 产生幻觉文本；前缀丢失 |
| 说话人分离需预注册 | resemblyzer 声纹匹配，必须提前录入声纹 | 新参会人/外部人员识别不出 |
| 热词可能不生效 | 若 8091 跑的是 SenseVoice，该模型不支持热词 | 政务术语（三重一大、党委前置）识别错误 |
| 1秒 chunk 批处理 | 非真正流式，上下文碎片化 | 延迟高，长句识别不稳 |

### 1.3 改造原则

1. **不破坏现有协议**：前端 WebSocket 协议（ready/preview/final/finished）保持不变，前端零改动
2. **不破坏 QwenASRClient 抽象**：现有 `start/chunk/finish` HTTP 协议保留，online pass 继续用它
3. **渐进式可回滚**：每个改造点都有开关，可通过配置一键回退到旧逻辑
4. **先 2pass 再三模型**：2pass 是收益最大的改造，优先实现；三模型串联中的 fsmn-vad 和 ct-punc 紧随其后；cam++ 说话人分离作为第三阶段

### 3.2 fsmn-vad 封装 (`backend/services/fsmn_vad.py`)

**职责**：封装 FunASR 的 fsmn-vad 模型，提供与现有 `SileroVAD` 兼容的 `process(pcm_bytes) -> (is_speech, prob)` 接口，同时支持回看缓冲。

**接口签名**：

```python
class FsmnVAD:
    def __init__(self, threshold: float = 0.5, sample_rate: int = 16000,
                 lookahead_packets: int = 2):
        """
        初始化 fsmn-vad。
        - threshold: 语音概率阈值
        - sample_rate: 采样率，固定16000
        - lookahead_packets: 回看缓冲包数，判定为语音时把缓冲里的包一起返回，防止前缀丢失
        """
        ...

    def process(self, pcm_bytes: bytes) -> tuple[bool, float]:
        """处理一帧PCM，返回(是否语音, 概率)。与 SileroVAD.process 签名一致。"""
        ...

    def process_with_lookahead(self, pcm_bytes: bytes) -> tuple[bool, float, list[bytes]]:
        """
        带回看缓冲的处理。
        返回: (is_speech, prob, pending_packets)
        - 当 is_speech=True 时，pending_packets 包含回看缓冲里的前缀包 + 当前包，应全部送入ASR
        - 当 is_speech=False 时，pending_packets 为空
        """
        ...

    def reset(self):
        """重置VAD状态和回看缓冲。新session时调用。"""
        ...
```

**实现要点**（AI 必须遵守）：

1. 模型加载：使用 `funasr.AutoModel(model="fsmn-vad")`，懒加载（单例），首次调用时加载
2. 输入处理：fsmn-vad 要求输入为 float32 numpy array，`pcm_bytes` 需 `np.frombuffer(dtype=np.int16).astype(np.float32) / 32768.0`
3. 回看缓冲：使用 `collections.deque(maxlen=lookahead_packets)`，每收到一包先入缓冲，判定为语音时把缓冲全部弹出返回
4. 状态管理：fsmn-vad 是有状态模型，需缓存上一次的 `cache` 参数传给下一次调用
5. 异常兜底：fsmn-vad 加载或推理失败时，自动降级到 SileroVAD（`from backend.silero_vad import SileroVAD`），并打 warning 日志
6. 与 SileroVAD 兼容：`process()` 方法签名和返回值必须与 `SileroVAD.process()` 完全一致，确保旧代码可无缝切换

**伪代码**：

```python
import logging
import numpy as np
from collections import deque
from typing import Optional

logger = logging.getLogger(__name__)

_model_instance = None
_model_lock = None  # asyncio.Lock，在使用时创建

def _get_model():
    global _model_instance
    if _model_instance is None:
        from funasr import AutoModel
        _model_instance = AutoModel(model="fsmn-vad", model_revision="v2.0.4")
    return _model_instance


class FsmnVAD:
    def __init__(self, threshold=0.5, sample_rate=16000, lookahead_packets=2):
        self.threshold = threshold
        self.sample_rate = sample_rate
        self.lookahead_packets = lookahead_packets
        self._buffer = deque(maxlen=lookahead_packets)
        self._cache = {}  # fsmn-vad 状态缓存
        self._fallback = None  # SileroVAD 降级实例

    def _to_float_array(self, pcm_bytes):
        return np.frombuffer(pcm_bytes, dtype=np.int16).astype(np.float32) / 32768.0

    def process(self, pcm_bytes):
        # 与 SileroVAD 兼容的接口
        is_speech, prob, _ = self.process_with_lookahead(pcm_bytes)
        return is_speech, prob

    def process_with_lookahead(self, pcm_bytes):
        self._buffer.append(pcm_bytes)
        try:
            model = _get_model()
            audio = self._to_float_array(pcm_bytes)
            result = model.generate(input=audio, cache=self._cache, is_final=False)
            # fsmn-vad 返回分段信息，从中提取语音概率
            # 具体返回格式需参考 FunASR 文档，这里用伪代码
            prob = self._extract_prob(result)
            self._cache = result.get("cache", self._cache)
        except Exception as e:
            logger.warning("fsmn-vad 推理失败，降级 SileroVAD: %s", e)
            if self._fallback is None:
                from backend.silero_vad import SileroVAD
                self._fallback = SileroVAD(threshold=self.threshold)
            is_speech, prob = self._fallback.process(pcm_bytes)
            if is_speech:
                pending = list(self._buffer)
                self._buffer.clear()
                return True, prob, pending
            return False, prob, []

        is_speech = prob >= self.threshold
        if is_speech:
            pending = list(self._buffer)
            self._buffer.clear()
            return True, prob, pending
        return False, prob, []

    def _extract_prob(self, result):
        # 从 fsmn-vad 输出中提取语音概率
        # 实际实现需根据 FunASR 返回格式调整
        if isinstance(result, list) and len(result) > 0:
            # 伪代码：取最大概率
            return max(item.get("prob", 0.0) for item in result) if result else 0.0
        return 0.0

    def reset(self):
        self._buffer.clear()
        self._cache = {}
        if self._fallback:
            self._fallback.reset()
```

### 3.3 Offline Pass 客户端 (`backend/services/offline_asr_client.py`)

**职责**：连接 offline ASR 服务（8092端口，跑 Qwen3-ASR-0.6B 或 paraformer-zh），对完整句子做高精度识别。与 `QwenASRClient` 的流式 start/chunk/finish 协议不同，offline 是**一次性提交整句音频，返回完整文本**。

**接口签名**：

```python
class OfflineASRClient:

        """健康检查。"""

    async def transcribe(self, pcm_bytes: bytes, sample_rate: int = 16000,

        Args:
            pcm_bytes: 整句PCM音频 (int16, 16kHz, 单声道)
            sample_rate: 采样率
            hotwords: 热词列表
            language: 强制语言，None为自动检测

            {"text": "完整文本", "language": "zh", "segments": [...], "duration": 12.5}
        """
        ...

    async def close(self):
        ...
```

**实现要点**：

1. 协议：offline 服务使用 OpenAI 兼容 API 或简单 HTTP POST。如果 8092 是 vLLM 部署的 Qwen3-ASR，用 `/v1/audio/transcriptions` 接口（OpenAI 兼容）；如果是 FunASR 部署的 paraformer-zh，用 FunASR 的 `/api/transcribe` 接口
2. 音频格式：PCM int16 16kHz，需封装为 WAV 或直接发送 bytes（取决于服务端协议）
3. 热词：Qwen3-ASR 支持热词，通过请求参数传入；paraformer-zh 也支持 hotwords 参数
4. 超时：单句超时默认 8 秒，超时后降级返回 online pass 的文本（不阻塞流程）
5. 单例：与 `QwenASRClient` 一样，在 `asr.py` 中维护全局单例

**伪代码**：

```python
import httpx
import logging
from typing import Optional

logger = logging.getLogger(__name__)


class OfflineASRClient:
    def __init__(self, base_url="http://127.0.0.1:8092", timeout=8.0, model="Qwen/Qwen3-ASR-0.6B"):
        self.base_url = base_url.rstrip("/")
        self.timeout = timeout
        self.model = model
        self._client: Optional[httpx.AsyncClient] = None

    async def _get_client(self):
        if self._client is None:
            self._client = httpx.AsyncClient(timeout=httpx.Timeout(self.timeout))
        return self._client

    async def close(self):
        if self._client:
            await self._client.aclose()
            self._client = None

    async def health(self) -> bool:
        try:
            client = await self._get_client()
            r = await client.get(f"{self.base_url}/health", timeout=3.0)
            return r.status_code == 200
        except Exception:
            return False

    async def transcribe(self, pcm_bytes, sample_rate=16000, hotwords=None, language=None):
        """
        转写整句音频。支持两种后端协议自动探测：
        1. vLLM OpenAI 兼容: POST /v1/audio/transcriptions (multipart/form-data)
        2. FunASR HTTP: POST /api/transcribe (raw bytes + params)
        """
        client = await self._get_client()

        # 策略：先尝试 vLLM OpenAI 兼容协议（Qwen3-ASR 推荐部署方式）
        try:
            return await self._transcribe_vllm(client, pcm_bytes, sample_rate, hotwords, language)
        except Exception as e:
            logger.debug("vLLM 协议失败，尝试 FunASR 协议: %s", e)
            return await self._transcribe_funasr(client, pcm_bytes, sample_rate, hotwords, language)

    async def _transcribe_vllm(self, client, pcm_bytes, sample_rate, hotwords, language):
        # vLLM 部署的 Qwen3-ASR 支持 OpenAI 兼容的 /v1/audio/transcriptions
        # 需要把 PCM 封装为 WAV bytes
        wav_bytes = self._pcm_to_wav(pcm_bytes, sample_rate)
        files = {"file": ("audio.wav", wav_bytes, "audio/wav")}
        data = {"model": self.model}
        if language:
            data["language"] = language
        if hotwords:
            data["hotwords"] = ",".join(hotwords[:100])  # vLLM 可能用逗号分隔

        r = await client.post(f"{self.base_url}/v1/audio/transcriptions", files=files, data=data)
        r.raise_for_status()
        result = r.json()
        return {
            "text": result.get("text", ""),
            "language": result.get("language", language or "auto"),
            "segments": result.get("segments", []),
            "duration": result.get("duration", 0.0),
        }

    async def _transcribe_funasr(self, client, pcm_bytes, sample_rate, hotwords, language):
        # FunASR HTTP 接口
        params = {"model": self.model, "sample_rate": sample_rate}
        if hotwords:
            params["hotwords"] = json.dumps(hotwords[:100])
        if language:
            params["language"] = language
        r = await client.post(
            f"{self.base_url}/api/transcribe",
            content=pcm_bytes,
            params=params,
            headers={"Content-Type": "application/octet-stream"},
        )
        r.raise_for_status()
        result = r.json()
        return {
            "text": result.get("text", ""),
            "language": result.get("language", "zh"),
            "segments": result.get("sentence_info", []),
            "duration": result.get("duration", 0.0),
        }

    @staticmethod
    def _pcm_to_wav(pcm_bytes, sample_rate=16000):
        """将 raw PCM int16 封装为 WAV 格式（含文件头）。"""
        import wave
        import io
        buf = io.BytesIO()
        with wave.open(buf, "wb") as wf:
            wf.setnchannels(1)
            wf.setsampwidth(2)  # 16-bit
            wf.setframerate(sample_rate)
            wf.writeframes(pcm_bytes)
        return buf.getvalue()
```

**实现要点**：

2. 推理：ct-punc 输入是纯文本字符串，输出是带标点的文本
3. 异步：标点恢复是 CPU 推理（ct-punc 很小），用 `asyncio.get_running_loop().run_in_executor(None, self.restore, text)` 包装为异步
4. 降级：模型加载失败时直接返回原文（不加标点），不阻塞流程
5. 缓存：对相同文本做简单 LRU 缓存（可选，减少重复推理）

```python
        self.device = device

                _get_model()
                self._ready = True

                logger.warning("ct-punc 加载失败，标点回退为原文: %s", e)
                self._ready = False

        self._ensure_ready()
        if not self._ready:
            return text
        try:
            model = _get_model()
            result = model.generate(input=text)

            return text
        except Exception as e:
            logger.warning("ct-punc 推理失败: %s", e)
            return text

    async def restore_async(self, text):
        loop = asyncio.get_running_loop()
        return await loop.run_in_executor(None, self.restore, text)

    def reset(self):
        pass  # ct-punc 无状态
```

### 3.6 ASR Engine 主类 (`backend/services/asr_engine.py`)

**职责**：整合 VAD + online pass + offline pass + 标点 + 后处理，对外提供一个统一的 `process_audio(pcm_bytes)` 接口，由 `asr.py` 的 `asr_worker` 调用。这是 2pass 架构的核心协调器。

**接口签名**：

```python
class ASREngine:

        """
        ...

        ...

        """重置所有状态。"""
        ...
```

**核心状态机**（AI 必须严格实现）：

```
状态: IDLE → SPEAKING → SENTENCE_END → SPEAKING → ... → FLUSH

IDLE:
  - 等待 VAD 检测到语音
  - 收到语音帧 → 进入 SPEAKING，启动 online session，累积 sentence_buffer

SPEAKING:
  - 每帧音频同时送入:
    a) online pass (流式，逐chunk出 preview)
    b) sentence_buffer (累积整句PCM，供 offline pass 使用)
  - 维护 silence_counter (连续静音帧数)
  - VAD 检测到非语音 → silence_counter++
  - silence_counter >= SENTENCE_END_SILENCE_MS (500ms) → 进入 SENTENCE_END

SENTENCE_END:
  - 取 sentence_buffer 中的整句PCM
  - 异步调用 offline pass (不阻塞后续音频处理)
  - offline 返回后:
    a) 标点恢复 (ct-punc)
    b) 后处理 (全量)
    c) 调用 on_final 回调，替换前端已显示的 preview
  - 清空 sentence_buffer，重置 silence_counter
  - 如果此时已有新的语音帧在缓冲 → 进入 SPEAKING；否则 → IDLE

FLUSH (finish 时):
  - 如果 sentence_buffer 非空 → 强制触发一次 offline pass
  - 关闭 online session
  - 关闭 offline client
```

**实现要点**：

1. **online session 管理**：复用 `QwenASRClient`，每句开始时 `start()`，句尾 offline 触发后 `finish()` 旧 session 并 `start()` 新 session（与现有 `asr_worker` 中的 session 重置逻辑一致）
2. **sentence_buffer**：`bytearray`，累积当前句子的所有 PCM 字节（包括 VAD 回看缓冲里的前缀），供 offline pass 使用
3. **silence_counter**：基于 VAD 结果计数，单位是毫秒（根据每包时长换算），达到 `ASR_SENTENCE_END_SILENCE_MS`（500ms）触发断句
4. **offline 异步**：offline pass 用 `asyncio.create_task()` 异步执行，不阻塞 `process_audio` 的主循环；offline 结果通过 `on_final` 回调发送
5. **offline 降级**：offline 服务不可用或超时时，直接用 online pass 的最后一版文本作为 final（加标点和后处理），不阻塞流程
6. **preview/final 对应关系**：每个句子有一个唯一的 `sentence_id`，preview 和 final 都携带此 id，前端据此替换显示（现有协议可能需要扩展，但后端先支持）
7. **长句断句**：单句超过 `ASR_SENTENCE_MAX_DURATION_MS`（15秒）强制断句，避免 offline 处理过长音频超时
8. **开关兼容**：`ASR_2PASS_ENABLED=False` 时，`ASREngine` 内部完全走旧逻辑（SileroVAD + 单 pass + 现有后处理），行为与改造前完全一致

**伪代码（核心部分）**：

```python
import asyncio
import logging
import time
from typing import Optional, Callable

logger = logging.getLogger(__name__)


class ASREngine:
    def __init__(self, config, on_preview=None, on_final=None, on_error=None):
        self.config = config
        self.on_preview = on_preview
        self.on_final = on_final
        self.on_error = on_error

        # 开关
        self.enabled = config.get("ASR_2PASS_ENABLED", True)
        self.offline_enabled = config.get("ASR_OFFLINE_ENABLED", True)
        self.punc_enabled = config.get("ASR_PUNC_ENABLED", True)

        # 组件
        self.vad = None  # FsmnVAD 或 SileroVAD
        self.online_client = None  # QwenASRClient
        self.offline_client = None  # OfflineASRClient
        self.punctuator = None  # PunctuationRestorer
        self.postprocessor = None  # ASRPostProcessor

        # 状态
        self.session_id = None
        self.sentence_buffer = bytearray()
        self.silence_ms = 0
        self.state = "IDLE"  # IDLE / SPEAKING / SENTENCE_END
        self.sentence_id = 0
        self.online_text = ""  # 当前句 online 累计文本
        self.committed_text = ""  # 已 final 的文本
        self.last_audio_time = 0
        self.sentence_start_time = 0

        # 配置参数
        self.sentence_end_silence_ms = config.get("ASR_SENTENCE_END_SILENCE_MS", 500)
        self.sentence_max_duration_ms = config.get("ASR_SENTENCE_MAX_DURATION_MS", 15000)
        self.chunk_bytes = 16000  # 1秒 @ 16kHz int16
        self.audio_buffer = bytearray()

    async def start(self, hotwords=None, metadata=None):
        # 初始化组件（懒加载）
        if self.config.get("ASR_VAD_BACKEND") == "fsmn":
            from backend.services.fsmn_vad import FsmnVAD
            self.vad = FsmnVAD(
                threshold=0.5,
                lookahead_packets=self.config.get("ASR_VAD_LOOKAHEAD_PACKETS", 2),
            )
        else:
            from backend.silero_vad import SileroVAD
            self.vad = SileroVAD(threshold=0.5)

        from backend.qwen_asr_client import QwenASRClient
        self.online_client = QwenASRClient(base_url=self.config.get("ASR_ONLINE_URL", "http://127.0.0.1:8091"))

        if self.offline_enabled:
            from backend.services.offline_asr_client import OfflineASRClient
            self.offline_client = OfflineASRClient(
                base_url=self.config.get("ASR_OFFLINE_URL", "http://127.0.0.1:8092"),
                model=self.config.get("ASR_OFFLINE_MODEL", "Qwen/Qwen3-ASR-0.6B"),
            )

        if self.punc_enabled:
            from backend.services.punctuation import PunctuationRestorer
            self.punctuator = PunctuationRestorer()

        from backend.services.asr_postprocess import ASRPostProcessor
        self.postprocessor = ASRPostProcessor()

        # 启动 online session
        if await self.online_client.is_available():
            self.session_id = await self.online_client.start(hotwords=hotwords, metadata=metadata)
        else:
            logger.warning("Online ASR 不可用")
            if self.on_error:
                await self.on_error("本地 ASR 不可用")

    async def process_audio(self, pcm_bytes):
        if not self.enabled:
            # 旧逻辑兼容：直接走单 pass（由调用方处理）
            await self._process_legacy(pcm_bytes)
            return

        # VAD 处理（带回看缓冲）
        if hasattr(self.vad, 'process_with_lookahead'):
            is_speech, prob, pending_packets = self.vad.process_with_lookahead(pcm_bytes)
        else:
            is_speech, prob = self.vad.process(pcm_bytes)
            pending_packets = [pcm_bytes] if is_speech else []

        # 计算每包时长（毫秒）
        packet_ms = int(len(pcm_bytes) / 32)  # 16kHz int16 = 32 bytes/ms

        if is_speech:
            # 语音帧
            self.silence_ms = 0
            if self.state == "IDLE":
                self.state = "SPEAKING"
                self.sentence_start_time = time.monotonic()
                self.sentence_id += 1
                self.online_text = ""
                # 确保有新的 online session
                if self.session_id is None:
                    await self._start_online_session()

            # 累积到 sentence_buffer (供 offline 使用)
            for pkt in pending_packets:
                self.sentence_buffer.extend(pkt)

            # 送入 online pass (累积到 chunk_bytes 才发)
            for pkt in pending_packets:
                self.audio_buffer.extend(pkt)
            while len(self.audio_buffer) >= self.chunk_bytes:
                chunk = bytes(self.audio_buffer[:self.chunk_bytes])
                del self.audio_buffer[:self.chunk_bytes]
                await self._send_online_chunk(chunk)

            # 长句强制断句
            sentence_duration_ms = (time.monotonic() - self.sentence_start_time) * 1000
            if sentence_duration_ms >= self.sentence_max_duration_ms:
                logger.info("长句强制断句: %.0fms", sentence_duration_ms)
                await self._trigger_sentence_end(force=True)

        else:
            # 非语音帧
            if self.state == "SPEAKING":
                self.silence_ms += packet_ms
                if self.silence_ms >= self.sentence_end_silence_ms:
                    await self._trigger_sentence_end()

    async def _send_online_chunk(self, chunk):
        if self.session_id is None:
            return
        try:
            result = await self.online_client.send_chunk(self.session_id, chunk)
            raw_text = str(result.get("text", "")).strip()
            # 后处理 (preview 只做轻量处理)
            text = self.postprocessor.process(raw_text, is_final=False) if self.postprocessor else raw_text
            if text and text != self.online_text:
                self.online_text = text
                full_text = self.committed_text + text
                if self.on_preview:
                    await self.on_preview(text, full_text, self.sentence_id)
        except Exception as e:
            logger.warning("Online chunk 失败: %s", e)
            # session 过期时重启
            if "session" in str(e).lower() or "expired" in str(e).lower():
                await self._restart_online_session()

    async def _trigger_sentence_end(self, force=False):
        self.state = "SENTENCE_END"
        sentence_pcm = bytes(self.sentence_buffer)
        self.sentence_buffer.clear()
        self.audio_buffer.clear()

        # finish 旧 online session
        if self.session_id:
            try:
                await self.online_client.finish(self.session_id)
            except Exception:
                pass
            self.session_id = None

        # online 最后一版文本 (作为 fallback)
        online_final_text = self.online_text

        # 异步触发 offline pass
        if self.offline_enabled and self.offline_client and len(sentence_pcm) > 3200:  # 至少100ms
            asyncio.create_task(self._run_offline_pass(sentence_pcm, online_final_text, self.sentence_id))
        else:
            # 无 offline，直接用 online 文本作为 final
            await self._finalize_sentence(online_final_text, self.sentence_id)

        # 重置状态，准备下一句
        self.state = "IDLE"
        self.silence_ms = 0

    async def _run_offline_pass(self, pcm_bytes, fallback_text, sentence_id):
        try:
            if not await self.offline_client.health():
                logger.warning("Offline ASR 不可用，使用 online 文本")
                await self._finalize_sentence(fallback_text, sentence_id)
                return

            result = await self.offline_client.transcribe(pcm_bytes, hotwords=self._current_hotwords)
            text = result.get("text", "").strip()
            if not text:
                text = fallback_text
            await self._finalize_sentence(text, sentence_id)
        except Exception as e:
            logger.warning("Offline pass 失败，降级 online 文本: %s", e)
            await self._finalize_sentence(fallback_text, sentence_id)

    async def _finalize_sentence(self, text, sentence_id):
        # 标点恢复
        if self.punc_enabled and self.punctuator:
            text = await self.punctuator.restore_async(text)
        # 全量后处理
        if self.postprocessor:
            text = self.postprocessor.process(text, is_final=True)
        # 提交
        self.committed_text += text
        if self.on_final:
            await self.on_final(text, self.committed_text, sentence_id)

    async def _start_online_session(self):
        try:
            if await self.online_client.is_available():
                self.session_id = await self.online_client.start(hotwords=self._current_hotwords)
        except Exception as e:
            logger.warning("Online session 启动失败: %s", e)

    async def _restart_online_session(self):
        if self.session_id:
            try:
                await self.online_client.finish(self.session_id)
            except Exception:
                pass
        self.session_id = None
        await self._start_online_session()

    async def finish(self):
        # flush 剩余音频
        if self.state == "SPEAKING" and self.sentence_buffer:
            await self._trigger_sentence_end(force=True)
        # flush online buffer 中剩余 chunk
        if self.audio_buffer and self.session_id:
            try:
                await self.online_client.send_chunk(self.session_id, bytes(self.audio_buffer))
            except Exception:
                pass
        if self.session_id:
            try:
                await self.online_client.finish(self.session_id)
            except Exception:
                pass
        if self.offline_client:
            await self.offline_client.close()
        # 等待 offline task 完成 (最多等3秒)
        # ... (实现时用 asyncio.gather 收集 task)

    def reset(self):
        if self.vad and hasattr(self.vad, 'reset'):
            self.vad.reset()
        self.session_id = None
        self.sentence_buffer.clear()
        self.audio_buffer.clear()
        self.silence_ms = 0
        self.state = "IDLE"
        self.sentence_id = 0
        self.online_text = ""
        self.committed_text = ""
```

- 模型：`Qwen/Qwen3-ASR-0.6B`（vLLM 部署，OpenAI 兼容 API）
- 协议：`/v1/audio/transcriptions`（OpenAI 兼容）
- 备选：`paraformer-zh`（FunASR 离线高精度）

**脚本内容**（AI 实现时需根据实际部署环境调整路径）：

```bash
#!/bin/bash
# 启动 ASR 双服务: online (8091) + offline (8092)
set -e

WORKDIR="/home/ai/ai616"
LOG_DIR="$WORKDIR/logs/asr"

echo "=== 1/2 启动 Online ASR (paraformer-zh-streaming, 8091) ==="
# 使用 FunASR 自带的 streaming server
```

## 五、注意事项与踩坑（AI 必须阅读）

### 5.1 模型部署踩坑

1. **FunASR 模型下载**：国内环境必须用 ModelScope 镜像（`hub="modelscope"`），HuggingFace 会超时。在 `AutoModel` 初始化时显式指定 `hub="modelscope"`
2. **vLLM 部署 Qwen3-ASR**：需要 vLLM nightly 版本（`uv pip install -U vllm --pre`），稳定版可能不支持音频输入。必须安装 `vllm[audio]` 额外依赖
3. **GPU 显存分配**：online (paraformer-streaming) 很小（<1GB），offline (Qwen3-ASR-0.6B) 约 4-6GB。如果只有单卡，online 用 CPU 跑（paraformer-streaming CPU 可实时），offline 用 GPU；如果双卡，online GPU0，offline GPU1
4. **模型版本锁定**：FunASR 模型指定 `model_revision="v2.0.4"`（或当前稳定版），避免自动拉取最新版导致接口变化

### 5.2 2pass 架构踩坑

1. **offline 异步任务泄漏**：`_run_offline_pass` 用 `asyncio.create_task()` 创建，必须在 `finish()` 时收集并等待所有 pending task，否则任务会被销毁导致 final 丢失。维护一个 `self._offline_tasks = set()`，创建时加入，完成时移除
2. **preview/final 替换**：前端需要支持根据 `sentenceId` 替换已显示的 preview 为 final。如果前端暂不支持，后端可以在 final 时不发送 `sentenceId`，直接追加文本（但会导致重复显示）。建议前端同步改造支持 sentenceId 替换
3. **online session 生命周期**：每句结束后必须 finish 旧 session 并 start 新 session，否则 online 模型的上下文会累积导致越来越慢、越来越不准。这与现有 `asr_worker` 中的 `stale_count` 重置逻辑一致
4. **sentence_buffer 内存**：长会议（1小时）如果不断句，buffer 会无限增长。必须有 `ASR_SENTENCE_MAX_DURATION_MS`（15秒）强制断句，且每句 final 后立即清空 buffer
5. **offline 超时阻塞**：offline pass 超时默认 8 秒，如果 offline 服务挂了，不能让这个超时阻塞主循环。用 `asyncio.wait_for()` 包裹，超时后降级用 online 文本

### 5.3 VAD 踩坑

1. **fsmn-vad 状态**：fsmn-vad 是有状态模型，必须把上一次的 `cache` 传给下一次，否则检测不准。在 `reset()` 时必须清空 cache
2. **回看缓冲与流式延迟的权衡**：`lookahead_packets=2` 增加约 400-500ms 延迟（假设每包 250ms），但能防止前缀丢失。如果对延迟极敏感，可设为 1（约 250ms），但前缀丢失风险增加
3. **SileroVAD 与 fsmn-vad 不要混用**：同一个 session 内只能用一种 VAD，切换会导致状态混乱。降级时（fsmn-vad 失败）应整个 session 都用 SileroVAD，不要来回切
4. **VAD 阈值**：fsmn-vad 的阈值语义和 SileroVAD 可能不同，不要直接复用 0.5。需要用实际会议音频调参，建议从 0.5 开始，根据误触发率和漏检率调整

### 5.4 标点恢复踩坑

1. **ct-punc 输入长度**：ct-punc 对过长文本（>500字）可能效果下降或超时。单句一般不超过 100 字，没问题；如果长句断句失效，需要在 `restore()` 中按长度分段处理
2. **ct-punc 与 ASR 自带标点冲突**：如果 online/offline ASR 模型已经输出了标点，ct-punc 可能重复加标点或位置错乱。在 `_finalize_sentence` 中先去除已有标点（正则去掉 `。，？！、；：`），再交给 ct-punc 统一加
3. **ct-punc CPU 推理**：ct-punc 很小（<100MB），CPU 推理延迟 <50ms，不需要 GPU。但必须用 `run_in_executor` 异步化，否则会阻塞事件循环

### 5.5 后处理踩坑

1. **同音词纠错的上下文**：现有 `_SYNONYM_CORRECTIONS` 是全局替换（`str.replace`），可能在非政务语境误替换（如"三种一大"在普通语境可能是对的）。建议加领域判断：只有当文本中包含其他政务关键词（如"党委""会议""审议"）时才启用政务同音词纠错
2. **口语顺滑的度**：去除口头禅不能太激进，否则会把正常用语删掉。只去除句首独立出现的（如句首的"嗯，""那个，"），不要去除句中的"那个"（可能是指示代词）
3. **数字归一化**：中文数字转阿拉伯数字有歧义（如"一百三"可能是"130"或"103"），建议只处理明确的模式（如"百分之X"→"X%"、"点X"→".X"），复杂模式保留原文

### 5.6 配置与回滚踩坑

1. **环境变量优先级**：所有 `ASR_*` 配置必须支持环境变量覆盖，且在 `config.py` 中有默认值。生产环境通过 `.env` 文件或 systemd `Environment=` 设置
2. **一键回滚**：`ASR_2PASS_ENABLED=false` 时必须完全回退到旧逻辑，包括 VAD（Silero）、单 pass、旧后处理、旧 silence_flush_monitor。回滚后行为必须与改造前完全一致，不能有残留状态
3. **灰度发布**：可以按用户/会议维度灰度（如只对特定 meetingId 启用 2pass），在 `meeting_asr_qwen_websocket` 中根据 `meeting_id` 判断是否启用。建议先内部测试会议灰度，稳定后全量
