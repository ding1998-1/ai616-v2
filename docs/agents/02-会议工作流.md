# Agent: 会议工作流 (Meeting Workflow)

## 功能概述

四阶段会议全生命周期管理：议题确认 → 会中采集与校对 → 会后终审 → 公文归档。

## 核心文件

| 文件 | 职责 |
|------|------|
| `frontend/src/pages/MeetingComplianceWorkflow.jsx` | 主页面（251KB），包含全部 4 阶段逻辑 |
| `frontend/src/pages/MeetingComplianceWorkflow.css` | 样式（75KB） |
| `frontend/src/pages/MobileMeetingRecorder.jsx` | 手机端录音页面 |
| `frontend/src/pages/IssueCollectPage.jsx` | 议题收集专用页面 |
| `backend_full.py` | 全部会议 API（CRUD、议题、议程、转写、纪要、归档） |

## 四阶段流程

### Stage 01: 议题确认 (collect)
- 录入议题（手动/Excel 导入/AI 生成）
- 绑定项目和审议事项
- AI 生成议程草案 (`POST /api/meetings/{id}/agenda/generate`)
- 冻结议程

### Stage 02: 会中采集与校对 (meeting)
- 桌面/手机麦克风开启
- 实时 ASR 转写 + 声纹分轨
- 转写文本校对 + 签名确认
- 标记决策/待办/争议/材料
- 议程实时对比 (`POST /api/meetings/{id}/agenda/realtime-check`)
- 会议计时器

### Stage 03: 会后终审 (audit)
- AI 分析全部转写，生成纪要/决议/待办
- Whisper 终审核验
- 材料核验
- 合规拦截检查

### Stage 04: 公文归档 (archive)
- 生成会议纪实 docx
- 签署确认
- 防伪归档

## 关键 API

| 端点 | 功能 |
|------|------|
| `POST /api/meetings` | 创建/更新会议 |
| `POST /api/meetings/{id}/stage` | 切换会议阶段 |
| `POST /api/meetings/{id}/issues` | 添加议题 |
| `POST /api/meetings/{id}/issues/import-excel` | Excel 导入议题 |
| `POST /api/meetings/{id}/agenda/generate` | AI 生成议程 |
| `GET /api/meetings/{id}/records` | 获取纪要/决议/待办 |
| `POST /api/meetings/{id}/records/update` | 更新纪要 |
| `GET /api/meetings/{id}/whisper-docx` | 下载终审纪实 docx |
| `GET /api/meetings/{id}/archive/docx` | 下载归档 docx |
| `POST /api/meetings/{id}/markers` | 添加标记 |
| `POST /api/meetings/{id}/{tid}/correction` | 转写校对 + 签名 |
| `GET /api/meetings/search` | 统一检索会议与议题，议题结果返回所属会议 |

## 数据库表

| 表 | 用途 |
|----|------|
| `meetings` | 会议主表（17 列） |
| `meeting_issue_sources` | 议题来源 |
| `meeting_agenda_drafts` | 议程草案 |
| `meeting_materials` | 会议材料 |
| `meeting_events` | 事件日志（转写、音频、session、stage） |
| `meeting_transcripts` | 转写记录（16 列） |
| `meeting_participants` | 参会人 |

## 二维码邀请

- 桌面端生成二维码，手机扫码进入 `MobileMeetingRecorder.jsx`
- URL: `{origin}/mobile-recorder?meetingId=xxx&meeting=标题&project=项目`
- 支持自定义外部访问地址（cpolar/ngrok/局域网 HTTPS）

## 状态管理

```
会议状态流转：
  创建 → collect → meeting → audit → archive
         (议题)    (录音)    (终审)   (归档)

录音状态：
  桌面: recording state → MediaRecorder + WebSocket ASR
  手机: MediaRecorder + WebSocket ASR → uploadRecordingAudio → postSession('stop')
```
