# 会后议题提取兜底修复计划

## 目标

修复会议已有真实讨论内容，但会后纪要只显示一个笼统议题或未提取出议题的问题。

## 内容判定规则

1. 录音转写是会后主题提取的主要事实来源。
2. 会前预设议题只作为关联参考，不能限制、替换或删除录音中真实出现的讨论主题。
3. 录音主题能与预设议题匹配时，保留关联信息。
4. 无法匹配预设议题时，仍按录音实际内容生成主题，并标记为“根据录音识别”，交由用户复核。
5. 没有逐字证据的模型结论不得自动升级为正式决议、风险或待办。

## 修复范围

- 修复“会议过程记录 1/10/11”等编号标题被误判为同一条的问题。
- 主题归并失败时，根据实际内容块数量和会议时长生成多个连续主题，避免整场会议只剩一个主题。
- 正式纪要主题未通过语义核验时，保留带逐字证据的录音主题候选，不再直接丢弃。
- 在纪要审核页明确显示“根据录音识别”和预设议题匹配结果。
- 记录主题归并失败原因，便于定位模型输出或上下文问题。

## 边界

- 不修改 H5 实时转写算法、分片、上传、录音合并及 Whisper 终审链路。
- 不修改 PC 录音链路。
- 不修改数据库结构。
- 不自动重跑或覆盖已经人工确认的生产会议。

## 验收条件

- 预设议题与实际讨论不一致时，页面仍能看到录音中提取出的真实主题。
- 预设议题匹配成功时，主题显示对应关联。
- 12 分钟以上且包含多个有效内容块的会议，模型归并失败后不再只剩一个主题。
- 编号不同的过程记录不会互相合并。
- 原有 H5 转写相关文件保持未改动。
