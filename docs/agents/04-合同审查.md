# Agent: 合同审查 (Contract Review)

## 功能概述

AI 驱动的合同风险分析系统，支持上传合同文档、自动识别风险点（锚定到文档位置）、在 OnlyOffice 中查看和修改、导出审查版。

## 核心文件

| 文件 | 职责 |
|------|------|
| `frontend/src/pages/CaseAnalysis.jsx` | 合同审查页面（90KB） |
| `backend_full.py` L6681 | 文档结构解析 (`POST /contract/map_doc_structure`) |
| `backend_full.py` L6720 | 合同分析 (`POST /contract/analyze`) |
| `backend_full.py` L6962 | 重新分析 (`POST /contract/re_analyze`) |
| `backend_full.py` L7136 | AI 起草 (`POST /contract/draft`) |
| `backend_full.py` L7164 | 导出起草 (`POST /contract/draft/export`) |

## 审查流程

```
上传 .docx
  → POST /doc/upload (插入书签)
  → POST /contract/map_doc_structure (解析文档结构)
  → POST /contract/analyze (AI 风险分析)
    → DeepSeek 分析每个段落
    → 返回 risk_level + issues (锚定到书签)
  → 前端展示风险列表
  → 点击风险项 → OnlyOffice 跳转到对应位置
  → 修改后可重新分析
  → POST /contract/draft/export (导出审查版)
```

## 风险分析结果格式

```json
{
  "bookmark": "bm_001",
  "risk_level": "high",
  "category": "违约责任",
  "issue": "违约金比例过高，超过合同标的的30%",
  "suggestion": "建议调整违约金比例为合同标的的15-20%",
  "regulation": "《民法典》第585条"
}
```

## 自定义规则

- 支持上传自定义审查规则 (`POST /api/custom_rules/upload`)
- 重新分析时可选择应用哪些规则
- 规则存储在 `data/custom_rules/`

## 数据存储

- 文档: `data/docs/{uuid}_{filename}.docx` + `.meta.json` (书签映射)
- 风险分析: `data/contracts/{filename}.issues.json`
