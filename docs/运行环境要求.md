# AI 合规系统 — 运行环境要求

> 评估日期：2026-06-18  
> 基于实测数据（当前运行环境：96核 / 503GB RAM / 2×RTX 4090）

---

## 一、配置结论（一句话）

**最低 2 核 4GB 能跑，推荐 4 核 8GB 流畅，不需要 GPU。**

---

## 二、实测资源占用

| 资源 | 实测占用 | 说明 |
|------|---------|------|
| 后端进程内存 | **~800 MB**（4 workers） | 每个 worker 约 200MB，含 embedding 模型 |
| Embedding 模型 | **~400 MB**（内存常驻） | `text2vec-base-chinese`，启动时加载一次 |
| ChromaDB 磁盘 | **43 MB** | 向量库持久化数据 |
| SQLite 磁盘 | **24 MB** | 会议/用户/转写等业务数据 |
| 文件存储 | **随使用增长** | 上传的合同/会议材料/音频，当前 ~500MB |
| Conda 环境磁盘 | **~8 GB** | Python + torch + langchain 等全部依赖 |
| Node 依赖磁盘 | **~775 MB** | 前端 node_modules（仅构建时需要） |
| HuggingFace 缓存 | **~1.5 GB** | 模型下载缓存（含 `text2vec-base-chinese` 391MB） |
| **总磁盘占用** | **~12 GB**（含系统依赖） | 纯应用代码+数据约 3GB |
| GPU | **不使用** | LLM 调远程 API，embedding 用 CPU |
| CPU | **空闲时 <1%** | 仅在 LLM 调用/文档解析/向量检索时短暂负载 |

## 三、分场景配置建议

### 场景 A：开发/测试（单用户）

| 配置项 | 最低 | 推荐 |
|--------|------|------|
| CPU | 2 核 | 4 核 |
| 内存 | 4 GB | 8 GB |
| 磁盘 | 20 GB | 50 GB SSD |
| GPU | 不需要 | 不需要 |
| 网络 | 能访问 DeepSeek API | 低延迟更好 |
| 系统 | Ubuntu 20.04+ / Debian 11+ / CentOS 7+ | Ubuntu 22.04 |

> 4GB 限制说明：embedding 模型 ~400MB + 2 个 uvicorn worker ~400MB + 系统 ~1.5GB + Nginx ~100MB ≈ 2.5GB 空闲内存。够用但不宽裕。8GB 舒适。

### 场景 B：团队内部使用（5-20 人）

| 配置项 | 最低 | 推荐 |
|--------|------|------|
| CPU | 4 核 | 8 核 |
| 内存 | 8 GB | 16 GB |
| 磁盘 | 50 GB SSD | 100 GB SSD |
| GPU | 不需要 | 不需要 |
| 网络 | 稳定公网 | 10Mbps+ 上行 |
| 系统 | Ubuntu 22.04 | Ubuntu 22.04 |

> 建议 4 个 uvicorn workers，支持 10-20 并发请求。音频文件会逐渐增加磁盘占用，建议定期清理或扩容。

### 场景 C：客户私有部署（>20 人，含 OnlyOffice）

| 配置项 | 最低 | 推荐 |
|--------|------|------|
| CPU | 8 核 | 16 核 |
| 内存 | 16 GB | 32 GB |
| 磁盘 | 100 GB SSD | 200 GB SSD |
| GPU | 不需要 | 不需要 |
| 网络 | 公网 + 域名 + HTTPS | 100Mbps+ |
| 系统 | Ubuntu 22.04 | Ubuntu 22.04 |

> OnlyOffice Document Server 单独需要 **4GB 内存**（Docker 容器）。如不需要在线编辑 Word 功能，可省去。

## 六、网络要求

| 目标 | 端口 | 协议 | 说明 |
|------|------|------|------|
| DeepSeek API | 443 | HTTPS | LLM 推理，必须可达 |
| 阿里云 DashScope | 443 | WSS | Fun-ASR 语音识别（仅手机录音时需要） |
| HuggingFace | 443 | HTTPS | 首次启动下载模型（可预下载跳过） |
| 用户访问 | 80/443 | HTTP/HTTPS | 前端页面 + API |

### 离线/内网部署注意

- **LLM API**：需要可访问 DeepSeek 或兼容 OpenAI 接口的内网 LLM 服务
- **语音识别**：如无外网，手机录音功能不可用（可降级为手动输入）
- **模型下载**：可提前在联网机器下载 `text2vec-base-chinese`，复制到离线机器
