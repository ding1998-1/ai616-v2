# AI 合规系统 — 项目总览

> 昇晟三重一大合规审核与法务对比系统

## 技术栈

| 层 | 技术 |
|----|------|
| 前端 | React 18 + Ant Design 6 + Vite |
| 后端 | FastAPI (Python) 单文件 `backend_full.py` (~7500 行) |
| 数据库 | SQLite (WAL 模式) + 内存缓存 |
| 向量库 | ChromaDB + text2vec-base-chinese |
| LLM | DeepSeek V3 (思维链流式) |
| ASR | Paraformer-Large (本地 GPU 1) + DashScope (云) |
| 文档 | OnlyOffice Document Server (Docker) |

## 数据流总览

```
用户操作
  │
  ├─ 合规审查 → DeepSeek LLM → SSE 流式结果
  ├─ 合同审查 → 文档解析 → DeepSeek 分析 → 风险列表
  ├─ 知识问答 → ChromaDB 检索 → DeepSeek 回答
  ├─ 会议录音 → WebSocket → ASR → 转写文本 → DeepSeek 纪要
  └─ 文档编辑 → OnlyOffice → 保存回调
  │
  └─ 全部数据 → SQLite + 文件系统
```

## 快速命令

```bash
# 健康检查
curl http://127.0.0.1:8002/health

# 重启后端
sudo systemctl restart ai-compliance

# 重启 ASR
sudo systemctl restart paraformer-asr

# 前端构建
cd /home/ai/文档/ai616/frontend && npm run build

# 查看日志
tail -f /home/ai/文档/ai616/logs/backend.log
journalctl -u paraformer-asr -f
```
