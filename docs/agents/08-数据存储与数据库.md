# Agent: 数据存储与数据库 (Data Storage)

## 功能概述

SQLite 数据库 + 文件系统存储，WAL 模式，内存缓存，自动备份。

## 核心文件

| 文件 | 职责 |
|------|------|
| `backend/db.py` | 数据库层（1549 行）：schema、CRUD、缓存、迁移 |
| `backend/config.py` | 路径常量、锁、缓存 TTL |
| `data/app.db` | 主数据库（25MB） |
| `data/backups/` | 自动备份目录 |

## SQLite 表结构

### meetings (会议主表)
| 列 | 类型 | 说明 |
|----|------|------|
| id | TEXT PK | 会议 ID |
| title | TEXT | 会议名称 |
| date | TEXT | 会议日期 |
| type | TEXT | 会议类型 |
| project | TEXT | 所属项目 |
| agenda | TEXT | 审议议题 |
| stage | TEXT | 当前阶段 |
| status | TEXT | 状态 |
| project_bound | BOOLEAN | 是否绑定项目 |
| agenda_frozen | BOOLEAN | 议程是否冻结 |
| review_done | BOOLEAN | 终审是否完成 |
| archive_done | BOOLEAN | 归档是否完成 |
| created_at | TEXT | 创建时间 |
| updated_at | TEXT | 更新时间 |
| ... | ... | 其他字段 |

### meeting_transcripts (转写记录)
| 列 | 类型 | 说明 |
|----|------|------|
| id | TEXT PK | 转写 ID |
| meeting_id | TEXT FK | 关联会议 |
| transcript | TEXT | 转写文本 |
| speaker_name | TEXT | 发言人姓名 |
| speaker_role | TEXT | 发言人角色 |
| is_final | BOOLEAN | 是否最终版 |
| confidence | REAL | 置信度 |
| client_time | TEXT | 客户端时间 |
| server_time | TEXT | 服务端时间 |
| correction_signed | BOOLEAN | 是否已签名校对 |
| correction_text | TEXT | 校对后文本 |

### meeting_events (事件日志)
| 列 | 类型 | 说明 |
|----|------|------|
| id | TEXT PK | 事件 ID |
| meeting_id | TEXT FK | 关联会议 |
| type | TEXT | 类型 (transcript/audio/session/stage) |
| server_time | TEXT | 时间 |
| payload_json | TEXT | JSON 负载 |
| sort_order | INTEGER | 排序 |

### 其他表
- `meeting_issue_sources` — 议题来源
- `meeting_agenda_drafts` — 议程草案
- `meeting_materials` — 会议材料
- `meeting_participants` — 参会人
- `notifications` — 通知
- `app_metadata` — 键值存储

## 缓存策略

| 数据 | TTL | 说明 |
|------|-----|------|
| meetings | 2 秒 | 会议列表内存缓存 |
| transcripts | 1 秒 | 转写记录内存缓存 |

## 文件系统存储

| 路径 | 内容 |
|------|------|
| `data/meeting_files/{meeting_id}/` | 会议材料文件 |
| `data/meeting_files/recordings/{meeting_id}/` | 录音文件 (.webm) |
| `data/docs/` | OnlyOffice 文档 |
| `data/contracts/` | 合同审查结果 |
| `data/knowledge_files/` | 知识库文件 |
| `data/custom_rules/` | 自定义规则 |
| `data/auth/` | 用户和部门数据 |
| `data/asr/` | ASR 热词和纠错表 |
| `data/backups/` | 数据库备份 |

## 备份

- 自动备份: 每天定时备份到 `data/backups/`
- 手动备份: `cp data/app.db data/backups/app_{timestamp}.db`
- WAL 检查点: 定期执行 `PRAGMA wal_checkpoint(TRUNCATE)`
