# H5 结束录音与会后处理修复

## 已知问题

- 结束按钮先等待全部上传 Promise，之后才显示结束进度；请求没有超时。
- 上传失败后 recording=false，结束按钮永久禁用，无法主动重试。
- 正常结束与页面恢复可能同时处理同一会话。
- PC 可以在手机录音尚未合并时进入会后终审，导致仅处理短录音。
- 生产恢复接口出现 403；尚不能据此认定用户切换了账号。

## 本次范围

1. 点击结束立即停止采集并显示保存状态，限制重复点击。
2. 上传与合并请求设置超时，保留本地分片和明确的重试入口。
3. 恢复流程与主动结束互斥，按当前账号处理会话，禁止借用其他账号凭证。
4. PC 会后处理前检查未合并录音；保留当前会议阶段并说明处理方法。
5. 保留所有原始录音文件，不修改数据库 Schema、认证配置或 GPU 服务。

## 验证

- 请求挂起、失败后重试、重复结束、同账号恢复和跨账号拒绝。
- 未合并录音阻止提前会后处理，已合并与无录音会议兼容。
- 相关后端测试、前端构建和浏览器模拟异常场景。
