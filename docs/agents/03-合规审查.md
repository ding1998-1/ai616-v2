# Agent: 合规审查 (Compliance Audit)

## 功能概述

"三重一大"事项合规审查系统，使用 DeepSeek LLM 进行 SSE 流式审查，支持思维链展示和风险雷达可视化。

## 核心文件

| 文件 | 职责 |
|------|------|
| `frontend/src/pages/ComplianceAudit.jsx` | 完整审查页面（77KB） |
| `frontend/src/pages/ComplianceAuditFocus.jsx` | 快速审查页面（31KB） |
| `backend_full.py` L4691 | 审查流式 API (`POST /audit_stream`) |
| `backend_full.py` L4917 | 模板生成 API (`POST /generate_template`) |
| `backend/llm_client.py` | DeepSeek LLM 客户端（支持思维链） |

## 审查流程

```
用户输入事项描述 + 上传材料
  → POST /audit_stream (SSE)
  → DeepSeek V3 流式推理
  → 思维链 (reasoning_content) 实时展示
  → 审查意见 + 风险等级 + 法规依据
  → 前端风险雷达可视化
```

## SSE 流式协议

```
data: {"type": "thinking", "content": "..."}     # 思维链
data: {"type": "content", "content": "..."}      # 正式内容
data: {"type": "done"}                           # 完成
data: {"type": "error", "message": "..."}        # 错误
```

## 审查维度

1. **事项类型审查**: 是否符合"三重一大"分类标准
2. **程序合规性**: 是否经过规定程序（党委会/董事会/总经理办公会）
3. **材料完整性**: 必备材料是否齐全
4. **法规依据**: 引用相关法规条款
5. **风险评估**: 风险等级（高/中/低）+ 风险点

## 与 OnlyOffice 集成

- 审查结果可锚定到文档书签
- OnlyOffice "Audit Navigator" 插件支持跳转到风险位置
- 支持导出带批注的审查版文档
