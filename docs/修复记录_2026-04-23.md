## 修复内容

### 1. Vite 代理配置 (`frontend/vite.config.js`)

**问题**：`/api/parse_file`、`/api/ingest_file`、`/api/doc/upload` 等前端请求通过 Vite 代理到后端时路径不匹配。后端路由没有 `/api` 前缀（如 `/parse_file`、`/ingest_file`、`/doc/upload`），但前端调用全部带 `/api` 前缀。

**修改**：
```js
// 之前（错误）：所有 /api/* 直接代理到后端，导致 /api/doc/upload -> 后端 /api/doc/upload (404)
'/api': { target: 'http://127.0.0.1:8000', changeOrigin: true }

// 之后：/api/doc/* 去掉 /api 前缀再转发，/api/knowledge_files/* 保持原前缀
'/api/doc': {
  target: 'http://127.0.0.1:8000',
  changeOrigin: true,
  rewrite: (path) => path.replace(/^\/api\/doc/, '/doc'),
},
'/api/knowledge_files': { target: 'http://127.0.0.1:8000', changeOrigin: true },
'/api/knowledge_files/': { target: 'http://127.0.0.1:8000', changeOrigin: true },
'/parse_file': { target: 'http://127.0.0.1:8000', changeOrigin: true },
'/ingest_file': { target: 'http://127.0.0.1:8000', changeOrigin: true },
'/doc': { target: 'http://127.0.0.1:8000', changeOrigin: true },
'/contract': { target: 'http://127.0.0.1:8000', changeOrigin: true },
```

### 2. 前端 parse_file/ingest_file 路径 (`frontend/src/pages/KnowledgeLibrary.jsx`)

**问题**：前端调用 `/api/parse_file` 和 `/api/ingest_file`，但 Vite 代理后端这两个路径时没有 `/api` 前缀。

**修改**：
```jsx
// 之前
const r1 = await fetch('/api/parse_file', { method: 'POST', body: fd1 });
const r2 = await fetch('/api/ingest_file', { method: 'POST', body: fd2 });

// 之后
const r1 = await fetch('/parse_file', { method: 'POST', body: fd1 });
const r2 = await fetch('/ingest_file', { method: 'POST', body: fd2 });
```

### 3. 前端 ComplianceAudit parse_file 路径 (`frontend/src/pages/ComplianceAudit.jsx`)

**问题**：合同审查页面的 `parseFile` 函数同样调用 `/api/parse_file`。

**修改**：
```jsx
// 之前
res = await fetch('/api/parse_file', { method: 'POST', body: fd });

// 之后
res = await fetch('/parse_file', { method: 'POST', body: fd });
```

### 4. 后端 vectorize 缺少 hashlib import (`backend_full.py`)

**问题**：`/api/knowledge_files/{file_id}/vectorize` 端点调用 `_compute_text_hash()` 时报错 `name 'hashlib' is not defined`。同时使用了错误的 `Blob` langchain 对象和 `vectorstore.add()` 方法。

**修改**：
- 添加 `import hashlib`
- 将 `vectorstore.add(documents=[blob.page_content], ...)` 改为 `vectorstore.add_texts(texts=[target["parsedText"]], ...)`

### 5. 后端 vectorize 使用了错误的 Blob API (`backend_full.py`)

**问题**：代码写了 `blob = Blob(page_content=..., metadata=...)` 但 langchain 的 Chroma wrapper 的 `add()` 方法只接受 strings，不是 Blob 对象。

**修改**：
```python
# 之前（错误）
blob = Blob(page_content=target["parsedText"], metadata={...})
vectorstore.add(documents=[blob.page_content], metadatas=[blob.metadata], ids=[target["id"]])

# 之后（正确）
vectorstore.add_texts(
    texts=[target["parsedText"]],
    metadatas=[{"source": target["name"], "file_id": target["id"]}],
    ids=[target["id"]]
)
```
