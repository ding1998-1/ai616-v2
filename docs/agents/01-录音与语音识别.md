# Agent: 录音与语音识别 (Meeting Recording & ASR)

## 功能概述

实时语音转写系统，支持手机端和桌面端录音，通过 WebSocket 将音频流式传输到 ASR 服务器进行实时识别。

## 核心文件

| 文件 | 职责 |
|------|------|
| `frontend/src/pages/MobileMeetingRecorder.jsx` | 手机端录音页面（77KB） |
| `frontend/src/pages/MeetingComplianceWorkflow.jsx` | 桌面端录音（集成在会议工作流中） |
| `backend_full.py` L4242 | 本地 ASR WebSocket handler (`/api/meeting/asr/qwen/ws`) |
| `backend_full.py` L3872 | DashScope 云 ASR WebSocket handler (`/api/meeting/asr/ws`) |
| `backend_full.py` L3165 | 录音会话管理 (`POST /api/meeting/recorder/session`) |
| `backend_full.py` L3252 | 录音文件上传 (`POST /api/meeting/recorder/audio`) |
| `backend_full.py` L3351 | 转写文本提交 (`POST /api/meeting/transcripts/chunk`) |
| `backend/qwen_asr_client.py` | ASR HTTP 客户端（start/chunk/finish 生命周期） |
| `/home/ai/桌面/funasr_asr_server.py` | ASR 推理服务（端口 8091） |

## 数据流

```
手机/桌面麦克风
  │  getUserMedia() → MediaRecorder (录音) + ScriptProcessor (实时ASR)
  │
  ├─ 录音文件路径：
  │    MediaRecorder → Blob → POST /api/meeting/recorder/audio
  │    → 保存到 data/meeting_files/recordings/{meeting_id}/audio_xxx.webm
  │    → DB meeting_events type='audio'
  │
  └─ 实时ASR路径：
       ScriptProcessor → PCM 16kHz → WebSocket binary
       → 后端 Energy Gate + VAD 过滤
       → 攒 600ms → HTTP POST /api/chunk → ASR 服务器 (8091)
       → ASR 返回文本 → LCP 去重 → WebSocket 推送 final/preview
       → 前端显示 + POST /api/meeting/transcripts/chunk 入库

停止录音：
  stopRecording()
    → uploadRecordingAudio()     // 保存录音文件
    → postSession('stop')        // 触发 Whisper 终审
      → _run_whisper_review()    // 后端读取 .webm → ffmpeg 转 PCM → Whisper 转写
      → _generate_whisper_meeting_docx()  // 生成终审纪实 docx
```

## ASR 服务器 (端口 8091)

**文件**: `/home/ai/桌面/funasr_asr_server.py`

| 端点 | 功能 |
|------|------|
| `GET /api/health` | 健康检查 |
| `POST /api/start` | 创建 ASR session |
| `POST /api/chunk?session_id=X` | 发送 PCM 音频块，返回识别文本 |
| `POST /api/finish?session_id=X` | 结束 session，返回最终文本 |
| `POST /api/transcribe` | Whisper 批量转写（兜底） |

**模型**: Paraformer-Large (流式) + CAM++ 说话人 + CT-Punc 标点 + Whisper-large-v3 (批量兜底)

## 后端过滤流水线 (WebSocket handler)

```
Stage 1: Energy Gate — 能量 + ZCR 联合判定，过滤静音和噪声
Stage 2: VAD-lite — 过零率语音检测（已合并到 Energy Gate）
Stage 3: 滑动缓冲区 — 攒 600ms (16000 bytes) 再发包
Stage 4: Paraformer 推理 — ASR 模型识别
Stage 5: LCP 裁剪 — 增量文本提取，去重
Stage 6: 重复 Token 熔断 — 连续 6 个相同汉字则重启 session
Stage 7: Preview/Final 推送 — 标点触发 final，≥8 字累积提交
Stage 8: 静默超时 — 0.8s 无变化则 flush 并重启 session
```

## 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| `energy_threshold` | 120 (自适应 80-250) | 能量门初始阈值 |
| `peak >= 200` | peak 阈值 | 峰值放行条件 |
| `ASR_CHUNK_BYTES` | 16000 | 500ms @ 16kHz |
| 静默超时 | 0.8s | 无变化则 flush |
| Session TTL | 10 分钟 | 自动过期 |

## Whisper 终审链路

```
录音停止 → postSession('stop')
  → _run_whisper_review()
    → 读取 recordings/{meeting_id}/*.webm
    → ffmpeg 转 PCM (16kHz mono)
    → POST /api/transcribe (ASR 服务器 Whisper-large-v3)
    → 结果写入 meeting_events type='transcript' action='whisper-review'
    → 触发 _generate_whisper_meeting_docx() 生成 docx
```
