# Agent: 部署与运维 (Deployment & Operations)

## 功能概述

系统部署、服务管理、nginx 配置、健康检查、日志管理。

## 服务架构

```
nginx (80/443)
  ├─ 静态文件: frontend/dist/
  ├─ API 代理: → 127.0.0.1:8002 (backend_full.py)
  ├─ WebSocket: /api/meeting/* → 127.0.0.1:8002
  └─ SSE: /audit_stream, /kb_stream → 127.0.0.1:8002

ai-compliance.service (端口 8002, GPU 0)
  └─ backend_full.py (FastAPI, conda env: ai_compliance)

paraformer-asr.service (端口 8091, GPU 1)
  └─ funasr_asr_server.py (FastAPI, conda env: funasr-sensevoice)

OnlyOffice Document Server (端口 8081, Docker)
```

## Systemd 服务

### ai-compliance.service
```ini
[Unit]
Description=AI 三重一大合规审核系统
After=network.target

[Service]
Type=simple
User=ai
WorkingDirectory=/home/ai/文档/ai616
ExecStart=/home/ai/miniconda3/envs/ai_compliance/bin/python backend_full.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

### paraformer-asr.service
```ini
[Unit]
Description=Paraformer ASR Server
After=network.target

[Service]
Type=simple
User=ai
WorkingDirectory=/home/ai/桌面
ExecStart=/home/ai/miniconda3/envs/funasr-sensevoice/bin/python funasr_asr_server.py --device cuda:1
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

## Nginx 配置

**文件**: `nginx-8002.conf` (简单版) / `nginx-fixed.conf` (生产版)

关键配置:
- 静态文件: `root /home/ai/文档/ai616/frontend/dist`
- API 代理: `proxy_pass http://127.0.0.1:8002`
- WebSocket: `proxy_set_header Upgrade $http_upgrade`
- SSE: `proxy_buffering off`
- 限流: 30r/m API, 5r/m LLM (nginx-fixed.conf)

## 重启命令

```bash
# 安全重启后端（推荐）
sudo /home/ai/文档/ai616/restart_safe.sh

# 简单重启
sudo systemctl restart ai-compliance

# 重启 ASR
sudo systemctl restart paraformer-asr

# 前端重新编译
cd /home/ai/文档/ai616/frontend && npm run build

# 全栈重启
sudo /home/ai/桌面/restart_all.sh
```

## 健康检查

```bash

curl http://127.0.0.1:8002/health

# ASR 健康

# 返回格式

  "status": "ok",
  "checks": {
    "db": "ok",
    "chromadb": "ok",
    "llm": "ok",
    "asr_dashscope": "ok",
    "asr_qwen": "ok"
  }
}
```

## 日志

| 日志 | 路径 | 内容 |
|------|------|------|
| 后端 | `/home/ai/文档/ai616/logs/backend.log` | API 请求、错误 |
| ASR | `journalctl -u paraformer-asr` | ASR 推理日志 |
| nginx | `/var/log/nginx/` | 访问日志、错误日志 |

## 环境变量

**文件**: `.env`

| 变量 | 说明 |
|------|------|
| `DEEPSEEK_API_KEY` | DeepSeek LLM API 密钥 |
| `DASHSCOPE_API_KEY` | DashScope ASR API 密钥 |
| `JWT_SECRET` | JWT 签名密钥 |
| `QWEN_ASR_URL` | 本地 ASR 地址 (默认 http://127.0.0.1:8091) |
