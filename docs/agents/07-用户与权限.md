# Agent: 用户与权限 (User Management)

## 功能概述

用户认证、角色管理、部门管理、会议角色绑定。

## 核心文件

| 文件 | 职责 |
|------|------|
| `frontend/src/pages/LoginPage.jsx` | 登录页面（33KB） |
| `frontend/src/pages/UserManagement.jsx` | 用户管理页面（18KB） |
| `frontend/src/lib/auth.js` | 认证工具（token 存储、authFetch） |
| `backend/routes/auth.py` | 认证路由（登录、注册、用户 CRUD） |
| `backend/deps.py` | 密码哈希、JWT、会议角色 |
| `backend/config.py` | JWT 密钥、环境变量 |
| `data/auth/users.json` | 用户数据 |
| `data/auth/departments.json` | 部门数据 |

## 认证流程

```
登录: POST /api/auth/login
  → 验证用户名 + 密码 (PBKDF2-SHA256)
  → 返回 JWT token
  → 前端存储到 localStorage

请求: Authorization: Bearer {token}
  → _get_user_from_auth_token() 验证
  → 注入 user 上下文
```

## 角色

| 角色 | 权限 |
|------|------|
| `admin` | 全部权限：用户管理、规则管理、会议管理 |
| `user` | 普通用户：审查、会议参与、知识库 |

| 参会代表 | 参与发言、查看材料 |
| 列席人员 | 旁听 |
